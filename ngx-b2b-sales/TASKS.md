# Tareas Frecuentes — B2B Sales Command Center

> Plantillas de tareas comunes en ventas B2B.

---

## 🔍 TAREA: Investigar Prospecto

### Input Requerido
- Nombre del prospecto o empresa
- Tipo (coach individual / gym / clínica)
- Fuente del lead (LinkedIn / referido / inbound)

### Output Esperado
- Research brief en markdown
- Guardado en `outputs/pipeline/research-[nombre]-[fecha].md`

### Checklist Específico
- [ ] Tamaño de negocio identificado
- [ ] Dolor probable documentado
- [ ] Ángulo de entrada definido
- [ ] Links a perfiles relevantes

---

## 📧 TAREA: Secuencia de Outreach

### Input Requerido
- Nombre y empresa del prospecto
- Dolor identificado
- Canal preferido (email / LinkedIn / WhatsApp)

### Output Esperado
- Email inicial + 3 follow-ups
- Guardado en `outputs/emails/outreach-[nombre]-[fecha].md`

### Checklist Específico
- [ ] Personalización real (no genérico)
- [ ] Cada mensaje agrega valor
- [ ] CTAs claros y simples
- [ ] Cadencia apropiada (3-5-7 días)

---

## 📞 TAREA: Preparar Discovery Call

### Input Requerido
- Nombre del prospecto
- Research previo (link al archivo)
- Fecha/hora de la llamada

### Output Esperado
- Script de discovery con preguntas
- Guardado en `outputs/scripts/discovery-[nombre]-[fecha].md`

### Checklist Específico
- [ ] Preguntas de descubrimiento listas
- [ ] Señales de fit/no-fit definidas
- [ ] Objeciones anticipadas
- [ ] Próximos pasos claros

---

## 📄 TAREA: Crear Propuesta

### Input Requerido
- Nombre y tipo de prospecto
- Información de discovery call
- Dolor principal y objetivo
- Precio acordado

### Output Esperado
- Propuesta completa en markdown
- Guardado en `outputs/proposals/[nombre]-proposal-[fecha].md`

### Checklist Específico
- [ ] Personalizada (no template genérico)
- [ ] Pricing correcto ($0 piloto → $199/mes)
- [ ] Timeline realista
- [ ] Próximos pasos claros
- [ ] FAQ incluido

---

## 📊 TAREA: Reporte de Pipeline

### Input Requerido
- Período a reportar
- Acceso a datos de pipeline (CRM o manual)

### Output Esperado
- Reporte ejecutivo semanal
- Guardado en `outputs/reports/pipeline-[fecha].md`

### Checklist Específico
- [ ] Métricas por etapa
- [ ] Deals calientes identificados
- [ ] Blockers documentados
- [ ] Acciones de próxima semana

---

## 📱 TAREA: Contenido LinkedIn B2B

### Input Requerido
- Tema o ángulo de la semana
- Cantidad de posts (típico: 3-5)
- Objetivo (awareness / engagement / leads)

### Output Esperado
- Posts completos listos para publicar
- Guardado en `outputs/linkedin/semana-[fecha].md`

### Checklist Específico
- [ ] Hooks fuertes
- [ ] Valor antes de venta
- [ ] CTAs sutiles
- [ ] Formatos variados

---

## 📚 TAREA: Case Study

### Input Requerido
- Nombre del cliente (Founding Coach)
- Situación antes de NGX
- Métricas de resultados
- Quote o testimonio

### Output Esperado
- Case study completo
- Guardado en `outputs/case-studies/[nombre]-[fecha].md`

### Checklist Específico
- [ ] Historia clara (antes → después)
- [ ] Métricas específicas
- [ ] Quote auténtico
- [ ] Permiso del cliente (verificar)

---

## 🎯 TAREA: Calificar Lead

### Input Requerido
- Información del lead
- Fuente del lead
- Interacción inicial (si hay)

### Output Esperado
- Evaluación de fit
- Score (1-10)
- Recomendación (Pursue / Nurture / Pass)

### Checklist Específico
- [ ] Criterios de Founding Coach evaluados
- [ ] Señales de compra identificadas
- [ ] Objeciones potenciales anticipadas
- [ ] Próximo paso definido

---

**INSTRUCCIÓN PARA CLAUDE CODE:**
Toda tarea B2B debe mantener tono profesional y respetar que el ciclo de venta es más largo. No presionar.
