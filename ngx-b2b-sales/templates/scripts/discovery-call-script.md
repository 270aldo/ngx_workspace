# Script: Discovery Call B2B

**Tipo:** Coaches / Gyms / Studios
**Duración:** 30 minutos
**Objetivo:** Calificar prospecto, entender necesidades, proponer siguiente paso

---

## Pre-Call Checklist

- [ ] Investigar LinkedIn del prospecto
- [ ] Revisar su sitio web/redes sociales
- [ ] Anotar 2-3 observaciones específicas
- [ ] Tener propuesta template lista
- [ ] Verificar que link de video funciona
- [ ] Tener demo accesible si la pide

---

## Estructura de la Call

| Sección | Tiempo | Objetivo |
|---------|--------|----------|
| Apertura | 2 min | Establecer rapport, confirmar tiempo |
| Contexto | 8 min | Entender su situación actual |
| Presentación | 10 min | Mostrar cómo NGX resuelve |
| Calificación | 5 min | Budget, timeline, decision maker |
| Cierre | 5 min | Definir siguiente paso |

---

## 1. Apertura (2 minutos)

### Saludo
```
"[Nombre], gracias por tomarte el tiempo. Antes de empezar,
¿tienes los 30 minutos completos o hay algo que debamos considerar?"
```

*Esperar confirmación*

### Establecer Agenda
```
"Perfecto. Mi objetivo hoy es:
1. Entender tu situación actual como [coach/gym owner]
2. Ver si NGX puede ayudarte genuinamente
3. Y si tiene sentido, definir un siguiente paso claro

¿Te parece bien esa estructura?"
```

### Romper el Hielo (opcional, si hubo research)
```
"Por cierto, vi que [observación específica de su LinkedIn/sitio].
¿Cómo ha sido esa experiencia?"
```

---

## 2. Contexto del Prospecto (8 minutos)

### Situación Actual

**Sobre su negocio:**
```
"Cuéntame sobre tu [práctica de coaching / gym / studio].
¿Cuántos clientes/miembros manejas actualmente?"
```

*Anotar: Número de clientes, tipo de servicio*

```
"¿Qué tipo de servicios ofreces principalmente?
¿Presencial, online, o híbrido?"
```

*Anotar: Modelo de negocio*

```
"¿Cuál es tu ticket promedio por cliente?"
```

*Anotar: Para calcular potencial*

### Herramientas Actuales

```
"¿Qué herramientas usas actualmente para gestionar a tus clientes?
Programación, seguimiento, comunicación..."
```

*Anotar: Tech stack actual, posibles integraciones*

```
"Del 1 al 10, ¿qué tan satisfecho estás con esas herramientas?"
```

*Si <7, profundizar:*
```
"¿Qué es lo que más te frustra de ellas?"
```

### El Dolor Principal

```
"Si pudieras resolver UN problema de tu operación mañana,
¿cuál sería?"
```

*Esta es la pregunta MÁS IMPORTANTE. Escuchar activamente.*

**Dolores comunes a escuchar:**
- "No tengo tiempo para dar seguimiento a todos"
- "Mis clientes no ven resultados consistentes"
- "Es difícil escalar sin perder calidad"
- "La retención/churn es un problema"
- "Competencia de apps baratas"

```
"¿Y cómo te afecta eso en el día a día / en el negocio?"
```

*Cuantificar el dolor si es posible*

---

## 3. Presentación NGX (10 minutos)

### Transición
```
"Basado en lo que me cuentas, especialmente [repetir dolor principal],
déjame explicarte cómo NGX podría ayudarte."
```

### Pitch Adaptado

**Si el dolor es TIEMPO:**
```
"NGX COACH te da un equipo de 13 agentes de IA que trabajan 24/7.
Ellos hacen el seguimiento diario, ajustes de planes, y comunicación.
Tú te enfocas en lo estratégico: las conversaciones de alto valor,
el coaching que realmente requiere un humano.

Coaches como tú reportan pasar de 2-3 horas por cliente a 30 minutos."
```

**Si el dolor es RESULTADOS:**
```
"El problema de la mayoría de apps es que son genéricas.
NGX tiene 13 agentes ESPECIALIZADOS que trabajan JUNTOS.

BLAZE ajusta el entrenamiento en tiempo real.
MACRO adapta la nutrición a lo que realmente comen.
LUNA optimiza su recuperación.

Todo coordinado. Por eso los resultados son más consistentes."
```

**Si el dolor es ESCALAR:**
```
"Hoy puedes manejar [N] clientes de calidad.
Con NGX, coaches están manejando 30, 40, hasta 50 clientes
sin sacrificar la experiencia.

Porque la IA hace la ejecución diaria.
Tú mantienes la relación y la estrategia."
```

**Si el dolor es CHURN:**
```
"El churn ocurre cuando el cliente no ve resultados o no siente seguimiento.
NGX resuelve ambos:

1. Resultados: 13 agentes optimizando TODO
2. Seguimiento: Comunicación automática pero personalizada

Los clientes sienten que tienes un equipo detrás, porque lo tienes."
```

### Demo Rápida (si el prospecto muestra interés)

```
"¿Te gustaría ver cómo se ve el dashboard?
Puedo compartir pantalla 2 minutos."
```

*Mostrar:*
1. Dashboard de coach (vista de todos los clientes)
2. Un perfil de cliente ejemplo
3. Cómo un agente hace una recomendación

```
"Esto es lo que verías tú. Y esto es lo que ve tu cliente en la app."
```

## 4. Calificación (5 minutos)

### Budget

```
"El programa [Founding Coaches / NGX COACH] tiene [pricing].
¿Es algo que encaja en tu presupuesto actual?"
```

**Si duda:**
```
"¿Cuál sería un rango que considerarías invertir
en una herramienta que [repite beneficio principal]?"
```

### Timeline

```
"¿Cuándo te gustaría tener algo así funcionando?"
```

**Respuestas a buscar:**
- "Lo antes posible" → HOT
- "Este mes/próximo mes" → WARM
- "Algún día" / "No sé" → Necesita nurturing

### Decision Maker

```
"¿Eres tú quien toma esta decisión o hay alguien más
que deba estar involucrado?"
```

**Si hay otro decisor:**
```
"Perfecto. ¿Te gustaría que agendemos una call con [esa persona]
o prefieres presentarle tú primero?"
```

### Objeciones Comunes

**"Es muy caro"**
```
"Entiendo. Déjame preguntarte: si con esto pudieras
[agregar 5 clientes más / retener 3 que iban a salir],
¿valdría la inversión?"
```

**"Necesito pensarlo"**
```
"Por supuesto. ¿Qué información adicional te ayudaría a decidir?
Te la envío y agendamos un follow-up de 15 min para [día]."
```

**"Ya tengo [otra herramienta]"**
```
"¿Qué hace [herramienta] particularmente bien para ti?
...
Interesante. La diferencia principal con NGX es [diferenciador clave].
¿Eso sería valioso en tu situación?"
```

**"Mis clientes no usarán otra app"**
```
"Es una preocupación válida. Lo que vemos es que cuando
la app realmente AYUDA y da RESULTADOS, los clientes la usan.
No es una app más de tracking. Es como tener un coach de bolsillo."
```

---

## 5. Cierre (5 minutos)

### Si Califica (Budget + Timeline + Authority OK)

```
"Me parece que hay un fit claro entre lo que necesitas y lo que NGX ofrece.

El siguiente paso sería:
1. Te envío la propuesta formal [hoy/mañana]
2. Agendamos un call de onboarding para [día próxima semana]
3. Empezamos con tus primeros 3 clientes

¿Te funciona?"
```

*Agendar AHORA mientras estás en la call*

### Si No Califica (Pero puede en el futuro)

```
"Aprecio tu tiempo y honestidad, [Nombre].

Creo que ahora mismo [razón: timing, budget, etc.] no es el mejor momento.
¿Te parece si te mantengo en el radar y te contacto cuando
[condición: termine tu contrato actual, tengas más clientes, etc.]?"
```

### Si Necesita Pensar (Pero mostró interés)

```
"Entiendo que es una decisión importante.

Esto es lo que propongo:
1. Te envío resumen de lo que hablamos + propuesta
2. Agendamos 15 minutos para [fecha específica, máximo 1 semana]
3. Ahí me dices tu decisión

¿Qué día te funciona mejor, [opción A] o [opción B]?"
```

## Post-Call Actions

### Inmediato (<30 min)
- [ ] Enviar email de resumen
- [ ] Actualizar CRM con notas
- [ ] Calificar lead (HOT/WARM/COLD)
- [ ] Crear tarea de follow-up

### Si Calificó (HOT)
- [ ] Enviar propuesta personalizada
- [ ] Confirmar call de onboarding
- [ ] Agregar a secuencia de closing

### Si Warm
- [ ] Enviar propuesta + materiales
- [ ] Programar follow-up en 3-5 días
- [ ] Agregar a secuencia de nurturing

### Si Cold
- [ ] Agregar a lista de nurturing largo plazo
- [ ] Programar check-in en 1-3 meses

## Notas para el Vendedor

### Mindset
- **Eres un consultor**, no un vendedor
- Tu trabajo es **descubrir si hay fit**, no forzar una venta
- **Escucha más de lo que hablas** (ratio 60/40)
- Si no hay fit, **está bien decirlo**

### Red Flags (No insistir)
- No tiene clientes actualmente
- Budget claramente insuficiente
- No toma decisiones
- Actitud de "convénceme"
- No responde a preguntas directas

### Green Flags (Cerrar pronto)
- Dolor claramente identificado
- Budget confirmado
- Timeline inmediato
- Es el decisor
- Hace preguntas específicas de implementación
