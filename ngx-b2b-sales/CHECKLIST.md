# Checklist de Calidad Pre-Entrega

> Todo output debe pasar este checklist antes de considerarse terminado.
> Claude Code debe ejecutar este checklist al final de cada tarea.

---

## ✅ Checklist Universal (Todos los Outputs)

### Precisión
- [ ] Precios correctos ($100 ASCEND, $1,200 HYBRID, $300 temporada ASCEND)
- [ ] Nombres de agentes correctos (NEXUS, BLAZE, ATLAS, TEMPO, WAVE, SAGE, METABOL, MACRO, NOVA, SPARK, STELLA, LUNA, LOGOS)
- [ ] Features mencionadas existen realmente
- [ ] No hay información inventada o alucinada

### Voz de Marca
- [ ] Tono "Verdad Directa" (confrontar con respeto, fundamentar con ciencia)
- [ ] Lenguaje apropiado para el segmento de edad
- [ ] Sin promesas exageradas o clickbait
- [ ] Tagline correcto: "Rinde hoy. Vive mejor mañana."

### Formato
- [ ] Headers claros y jerárquicos
- [ ] Guardado en carpeta `outputs/` correcta
- [ ] Nombre de archivo descriptivo
- [ ] Fecha incluida si aplica

### Proceso
- [ ] MEMORY.md actualizado con tarea completada
- [ ] No contradice DECISIONS.md
- [ ] No viola reglas de DO_NOT.md

---

## 📧 Checklist Específico: Emails

- [ ] Subject line < 50 caracteres
- [ ] Preview text definido
- [ ] Un solo CTA principal
- [ ] Párrafos cortos (3-4 líneas máximo)
- [ ] Personalización (nombre, contexto)
- [ ] Firma apropiada
- [ ] Links funcionales indicados

---

## 📝 Checklist Específico: Copy/Ads

- [ ] Hook en primeras 3 palabras
- [ ] Beneficio claro, no feature
- [ ] Urgencia sin ser spam
- [ ] CTA específico y accionable
- [ ] Longitud apropiada para plataforma

---

## 🎙️ Checklist Específico: Scripts (Podcast/Video)

- [ ] Duración estimada indicada
- [ ] Personalidades de agentes correctas
- [ ] Diálogos naturales, no robóticos
- [ ] Momentos de tensión/resolución
- [ ] Llamadas a acción integradas orgánicamente

---

## 📄 Checklist Específico: Documentos/PRDs

- [ ] Problema claramente definido
- [ ] Solución específica y medible
- [ ] Criterios de éxito definidos
- [ ] Dependencias identificadas
- [ ] Riesgos documentados

---

## 🤝 Checklist Específico: Propuestas B2B

- [ ] Nombre del prospecto correcto
- [ ] Dolor específico identificado
- [ ] ROI o beneficio cuantificado
- [ ] Timeline realista
- [ ] Próximos pasos claros

---

## Cómo Usar

### Al Terminar Cualquier Tarea:
```
1. Ejecutar checklist universal
2. Ejecutar checklist específico (si aplica)
3. Corregir cualquier [ ] sin marcar
4. Solo entonces entregar al usuario
```

### Si Algo No Pasa:
```
1. Identificar el problema
2. Corregir antes de entregar
3. Si no es posible corregir, informar al usuario
```

---

**INSTRUCCIÓN PARA CLAUDE CODE:**
Nunca entregues un output sin haber pasado el checklist. Si tienes dudas sobre algún punto, pregunta al usuario.
