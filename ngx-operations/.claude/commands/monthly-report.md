# Monthly Report

Genera reporte mensual completo.

## Instrucciones

1. Solicita métricas completas del mes
2. Revisa weekly reviews del mes
3. Compara con objetivos y mes anterior
4. Genera documento ejecutivo

## Output

Documento 2-3 páginas:
- Resumen ejecutivo
- Dashboard de métricas
- Análisis de resultados
- Top 3 logros y problemas
- Plan de acción para siguiente mes
