# SOP Create

Crea un SOP (Standard Operating Procedure) nuevo.

## Instrucciones

1. Pregunta nombre del proceso
2. Pregunta qué hace y cuándo se ejecuta
3. Pregunta pasos actuales
4. Pregunta herramientas necesarias
5. Genera SOP estructurado

## Output

Archivo markdown en /sops/ con:
- Objetivo del proceso
- Trigger (qué lo inicia)
- Pasos numerados
- Checklist de verificación
- Troubleshooting
- Output esperado
