# Metrics Dashboard

Genera dashboard de métricas.

## Instrucciones

1. Pregunta qué KPIs incluir
2. Solicita datos del período
3. Pregunta período de comparación
4. Genera dashboard HTML

## Output

Dashboard HTML en /dashboards/ con:
- Visualización de KPIs
- Comparación vs período anterior
- Indicadores de tendencia
- Estilo NGX dark theme
