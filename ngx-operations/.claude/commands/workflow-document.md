# Workflow Document

Documenta un workflow de n8n.

## Instrucciones

1. Pregunta nombre del workflow
2. Pregunta propósito y trigger
3. Pregunta nodos principales
4. Solicita dependencias (APIs, credenciales)
5. Genera documentación completa

## Output

Documentación markdown con:
- Descripción general
- Diagrama mermaid
- Inputs/Outputs
- Dependencias
- Troubleshooting
- Cómo modificar
