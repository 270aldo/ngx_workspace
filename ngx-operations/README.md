# NGX Operations Hub

Centro de comando para operaciones diarias de NGX.

## Quick Start

```bash
cd ngx-operations
claude
/start-session
```

## Propósito

- SOPs y procedimientos
- Métricas y dashboards
- Workflows y automatizaciones
- Reportes operativos

## Comandos Principales

- `/daily-checklist` — Planificar el día
- `/weekly-review` — Reporte semanal
- `/sop-create` — Crear nuevo SOP
- `/metrics-dashboard` — Generar dashboard

## Estructura

```
├── CLAUDE.md          # Instrucciones principales
├── MEMORY.md          # Estado entre sesiones
├── sops/              # Procedimientos
├── dashboards/        # Dashboards HTML
└── outputs/           # Entregas
```
