# Invoice Create

Genera factura para cliente.

## Instrucciones

1. Solicita datos del cliente
2. Solicita producto/servicio
3. Solicita monto y período
4. Genera factura estructurada
5. Guarda en /outputs/invoices/

## Output

Factura markdown con:
- Número único (NGX-YYYYMM-NNN)
- Datos completos
- Desglose de servicios
- Instrucciones de pago
