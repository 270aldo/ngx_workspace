# Projection Create

Crea proyección financiera.

## Instrucciones

1. Solicita datos actuales
2. Define supuestos de crecimiento
3. Genera 3 escenarios
4. Calcula break-even por escenario

## Output

Proyección con:
- Escenario conservador (50%)
- Escenario base (100%)
- Escenario optimista (150%)
- MRR mes a mes
- Break-even estimado
