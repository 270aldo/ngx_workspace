# Finance Standards

## Números
- Siempre verificar antes de usar
- Nunca inventar datos financieros
- Mostrar fuente cuando sea posible

## Proyecciones
- Conservadoras por defecto
- 3 escenarios siempre
- Supuestos explícitos

## Reportes
- P&L mensual obligatorio
- Runway actualizado mensualmente
- Comparación siempre incluida

## Facturas
- Numeración: NGX-YYYYMM-NNN
- Emitir dentro de 48h de venta
- Guardar en /outputs/invoices/
