# NGX Finance

Centro de control financiero para NGX.

## Quick Start

```bash
cd ngx-finance
claude
/start-session
```

## Propósito

- P&L y reportes financieros
- Proyecciones y forecasts
- Budget tracking
- Facturación

## Comandos Principales

- `/monthly-pnl` — P&L mensual
- `/runway-calc` — Calcular runway
- `/projection-create` — Crear proyección
- `/invoice-create` — Generar factura

## Estructura

```
├── CLAUDE.md          # Instrucciones principales
├── MEMORY.md          # Estado entre sesiones
├── dashboards/        # Dashboards financieros
├── templates/         # Templates
└── outputs/           # Reportes y facturas
```
