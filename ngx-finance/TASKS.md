# NGX Finance — Tareas Frecuentes

> Flujos optimizados para tareas financieras recurrentes.

---

## 1. Monthly P&L

**Frecuencia:** Primeros días de cada mes

**Input requerido:**
- Ingresos por producto
- Gastos por categoría
- Período a reportar

**Output esperado:**
- P&L estructurado
- Comparación vs mes anterior
- Análisis de variaciones

**Checklist:**
- [ ] Todos los ingresos incluidos
- [ ] Todos los gastos categorizados
- [ ] Totales verificados
- [ ] Comparación con período anterior
- [ ] Notas sobre variaciones >10%

---

## 2. Runway Calculation

**Frecuencia:** Mensual o cuando cambie situación

**Input requerido:**
- Caja actual
- MRR actual
- Burn rate mensual
- Proyección de crecimiento

**Output esperado:**
- Runway en meses
- Fecha estimada de agotamiento
- Recomendaciones si runway < 12 meses

**Checklist:**
- [ ] Caja actualizada
- [ ] Burn rate correcto
- [ ] Escenario sin crecimiento calculado
- [ ] Escenario con crecimiento calculado
- [ ] Fecha crítica identificada

---

## 3. Financial Projection

**Frecuencia:** Mensual o para decisiones importantes

**Input requerido:**
- Datos actuales (clientes, MRR, gastos)
- Supuestos de crecimiento
- Período a proyectar

**Output esperado:**
- 3 escenarios (conservador, base, optimista)
- Proyección mes a mes
- Break-even estimado

**Checklist:**
- [ ] Supuestos documentados y realistas
- [ ] 3 escenarios generados
- [ ] MRR y gastos proyectados
- [ ] Break-even calculado
- [ ] Sensibilidad a supuestos clave

---

## 4. Budget Review

**Frecuencia:** Semanal (quick) o mensual (completo)

**Input requerido:**
- Presupuesto por categoría
- Gastos reales del período

**Output esperado:**
- Comparación presupuesto vs real
- Variaciones por categoría
- Alertas y recomendaciones

**Checklist:**
- [ ] Todas las categorías revisadas
- [ ] Variaciones calculadas
- [ ] Causas de variaciones >10% identificadas
- [ ] Acciones correctivas propuestas
- [ ] Presupuesto ajustado si necesario

---

## 5. Unit Economics Analysis

**Frecuencia:** Trimestral o cuando cambie el modelo

**Input requerido:**
- Precio por producto
- CAC
- Churn rate
- Costos por cliente

**Output esperado:**
- LTV, LTV:CAC, Payback period
- Evaluación de viabilidad
- Palancas de mejora

**Checklist:**
- [ ] LTV calculado correctamente
- [ ] LTV:CAC > 3 (o justificación)
- [ ] Payback < 12 meses (o plan)
- [ ] Márgenes positivos
- [ ] Recomendaciones accionables

---

## 6. Invoice Creation

**Frecuencia:** Cuando hay venta

**Input requerido:**
- Datos del cliente
- Producto/servicio
- Monto
- Período

**Output esperado:**
- Factura en formato markdown/PDF
- Guardada en /outputs/invoices/

**Checklist:**
- [ ] Número de factura único
- [ ] Datos del cliente correctos
- [ ] Monto y concepto claros
- [ ] Instrucciones de pago incluidas
- [ ] Archivo guardado correctamente

---

## 7. Cost Optimization Review

**Frecuencia:** Trimestral

**Input requerido:**
- Lista completa de gastos
- Clasificación por importancia

**Output esperado:**
- Oportunidades de ahorro priorizadas
- ROI de cada optimización
- Plan de implementación

**Checklist:**
- [ ] Todos los gastos revisados
- [ ] Clasificados por esencial/nice-to-have
- [ ] Alternativas investigadas
- [ ] Ahorros cuantificados
- [ ] Priorización por impacto/esfuerzo

---

## 8. Revenue Forecast

**Frecuencia:** Mensual

**Input requerido:**
- Clientes actuales
- Pipeline de ventas
- Tasas de conversión históricas
- Churn esperado

**Output esperado:**
- Forecast por producto y total
- Rango de confianza
- Riesgos identificados

**Checklist:**
- [ ] Todos los productos incluidos
- [ ] Pipeline considerado con tasa de conversión
- [ ] Churn aplicado
- [ ] Rango pesimista-optimista
- [ ] Supuestos documentados

---

## 9. Cash Flow Projection

**Frecuencia:** Mensual

**Input requerido:**
- Caja inicial
- Entradas proyectadas
- Salidas proyectadas
- Inversiones planeadas

**Output esperado:**
- Flujo mensual
- Saldo acumulado
- Alertas de caja negativa

**Checklist:**
- [ ] Caja inicial correcta
- [ ] Todas las entradas incluidas
- [ ] Todos los gastos incluidos
- [ ] Inversiones consideradas
- [ ] Punto bajo de caja identificado

---

## 10. Investment Decision

**Frecuencia:** Cuando surge oportunidad

**Input requerido:**
- Inversión requerida
- Beneficios esperados (cuantificados)
- Alternativas

**Output esperado:**
- Análisis ROI
- Recomendación go/no-go
- Condiciones para reconsiderar

**Checklist:**
- [ ] ROI calculado a 6 y 12 meses
- [ ] Payback period estimado
- [ ] Riesgos identificados
- [ ] Alternativas consideradas
- [ ] Recomendación clara con justificación

---

*Cada tarea sigue el patrón: Input → Proceso → Output → Verificación*
