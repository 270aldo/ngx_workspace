# Reglas de Voz de Marca NGX

Estas reglas aplican a TODO el contenido generado en este workspace.

## Voz "Verdad Directa"

**Definición:** "Confrontamos con respeto, fundamentamos con ciencia, resolvemos con sistemas."

## Reglas Absolutas

### NUNCA hacer
- Usar arquetipos PRIME o LONGEVITY (obsoletos)
- Mencionar "ejecutivos" o "CEOs" como segmento principal
- Hacer promesas absolutas ("100% garantizado", "resultados asegurados")
- Usar más de 1-2 emojis por pieza de contenido
- Usar mayúsculas excesivas (ESTO ESTÁ MAL)
- Usar múltiples signos de exclamación (¡¡¡Increíble!!!)
- Crear urgencia falsa ("Solo quedan 3 lugares")
- Usar cyan como color (siempre violeta #6D00FF)
- Escribir como "gurú fitness" con hype vacío
- Usar caras exageradas de sorpresa en visuales

### SIEMPRE hacer
- Adaptar tratamiento según audiencia (tú para 30-45, usted para 45-60)
- Mencionar al agente correcto para cada función
- Explicar términos técnicos cuando se usen
- Terminar con una acción concreta
- Admitir limitaciones antes de vender beneficios
- Mantener "Confianza Tranquila" - seguridad sin gritar
- Usar la fórmula CONFRONTA → FUNDAMENTA → RESUELVE cuando aplique

## Los 3 Modos

### Modo A - El Experto
- **Cuándo:** Educar, explicar el "por qué"
- **Energía:** Media
- **Frase tipo:** "Te explico cómo funciona..."

### Modo B - La Verdad
- **Cuándo:** Captar atención, hooks, romper mitos
- **Energía:** Alta
- **Frase tipo:** "El problema no eres tú..."

### Modo C - El Arquitecto
- **Cuándo:** Mostrar sistema, convertir
- **Energía:** Reservada
- **Frase tipo:** "Esto es lo que construimos..."

## Selector de Modo

| Formato | Modo Recomendado |
|---------|------------------|
| Hook / Ad / Reel | B - Verdad |
| Video largo / Blog | A - Experto |
| Landing / Email venta | C - Arquitecto |

## Checklist Pre-Publicación

Antes de finalizar cualquier contenido, verificar:

- [ ] Tratamiento correcto (tú/usted)
- [ ] Sin términos prohibidos
- [ ] Agente correcto mencionado
- [ ] Términos técnicos explicados
- [ ] Acción concreta al final
- [ ] Limitaciones admitidas si aplica
- [ ] Tono "Verdad Directa"
- [ ] Visual con violeta #6D00FF
- [ ] Máximo 1-2 emojis
