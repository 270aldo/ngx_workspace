# Tareas Frecuentes — Marketing Command Center

> Plantillas de tareas comunes. Usar para no explicar cada vez.

## 📧 TAREA: Email Sequence Nuevo Lead

### Input Requerido
- Nombre del lead magnet
- Temperatura del lead (frío/tibio/caliente)
- Objetivo (ASCEND/HYBRID)
- Audiencia (30-45/45-60)

### Output Esperado
- 5-7 emails en markdown
- Guardados en `outputs/emails/[nombre]-sequence-[fecha]/`
- Cada email con: subject, preheader, body, CTA

### Checklist Específico
- [ ] Precios correctos mencionados
- [ ] Un solo CTA por email
- [ ] Tono Verdad Directa
- [ ] Progresión lógica de emails

## 📱 TAREA: Batch de Ads

### Input Requerido
- Plataforma (Meta/Google/LinkedIn)
- Producto (ASCEND/HYBRID/Lead Magnet)
- Audiencia target
- Dolor principal a atacar
- Cantidad de variaciones (3-5)

### Output Esperado
- Variaciones de copy en markdown
- Guardadas en `outputs/ads/[campaña]-[fecha].md`
- Sugerencias de creativos incluidas

### Checklist Específico
- [ ] Dentro de límites de caracteres
- [ ] CTAs claros
- [ ] Sin promesas exageradas
- [ ] Hook en primeras palabras

## 📊 TAREA: Auditoría de Funnel

### Input Requerido
- Nombre del funnel
- URLs de cada paso (o descripción)
- Métricas actuales (si disponibles)

### Output Esperado
- Reporte completo en markdown
- Guardado en `outputs/audits/[funnel]-audit-[fecha].md`
- Score por elemento + recomendaciones

### Checklist Específico
- [ ] Todos los pasos analizados
- [ ] Recomendaciones priorizadas
- [ ] Quick wins identificados
- [ ] Próximos pasos claros

## 📱 TAREA: Contenido Social Semanal

### Input Requerido
- Plataforma(s) objetivo
- Tema de la semana
- Cantidad de posts (típico: 5)
- Fechas específicas (opcional)

### Output Esperado
- Posts completos con copy y sugerencia visual
- Guardados en `outputs/social/semana-[fecha]/`
- Un archivo por post o todos juntos

### Checklist Específico
- [ ] Variedad de formatos
- [ ] Hooks fuertes
- [ ] Valor antes de venta
- [ ] CTAs apropiados para cada post

## 🔄 TAREA: Preparar Llamada HYBRID

### Input Requerido
- Nombre del lead

- Información conocida (dolor, objetivo)
- Fecha de la llamada

### Output Esperado
- Brief de llamada en markdown
- Guardado en `outputs/hybrid/call-prep-[nombre]-[fecha].md`
- Estructura de llamada + objeciones

### Checklist Específico

- [ ] Objeciones anticipadas

- [ ] Próximos pasos definidos

## Cómo Usar Este Archivo

1. **Identificar** la tarea que vas a hacer
2. **Verificar** que tienes todos los inputs requeridos
3. **Ejecutar** usando el prompt correspondiente de PROMPTS.md
4. **Verificar** que el output cumple el checklist específico
5. **Guardar** en la ubicación indicada
