# Tareas Frecuentes - Marketing

> Plantillas de tareas comunes con inputs/outputs definidos.

---

## 1. Email Sequence para Lead Magnet

### Input Requerido
- Nombre del lead magnet
- Temperatura del lead (fría/tibia/caliente)
- Producto objetivo (ASCEND/HYBRID)
- Audiencia (30-45/45-60)

### Output
- 7 emails en `outputs/emails/[lead-magnet]-sequence/`
- Cada email: subject, preheader, body, CTA

### Tiempo Estimado
~15 minutos

---

## 2. Batch de Ads (5 variaciones)

### Input Requerido
- Plataforma (Meta/Google/LinkedIn)
- Producto (ASCEND/HYBRID/Lead Magnet)
- Ángulo/dolor principal
- Audiencia target

### Output
- 5 variaciones en `outputs/ads/[campaña]-variations.md`
- Cada variación: headline, body, CTA

### Tiempo Estimado
~10 minutos

---

## 3. Audit de Funnel

### Input Requerido
- URL o descripción del funnel actual
- Métricas actuales (si disponibles)
- Objetivo del funnel

### Output
- Reporte en `outputs/audits/funnel-[fecha].md`
- Score por área (1-10)
- Recomendaciones priorizadas

### Tiempo Estimado
~20 minutos

---

## 4. Contenido Social Semanal

### Input Requerido
- Plataforma principal
- Tema de la semana
- Formato preferido

### Output
- 5 posts en `outputs/social/semana-[fecha]/`
- Mix: 3 educativos, 1 autoridad, 1 engagement

### Tiempo Estimado
~15 minutos

## 5. Script de Calificación HYBRID

### Input Requerido
- Nombre del lead
- Fuente de entrada
- Información conocida del lead

### Output
- Script en `outputs/hybrid/calificacion-[nombre].md`
- Preguntas de calificación
- Criterios de decisión
- Siguiente paso según resultado

### Tiempo Estimado
~10 minutos

## 6. Brief de Llamada de Cierre

### Input Requerido

### Output

### Tiempo Estimado

## 7. Reporte Semanal de Marketing

### Input Requerido
- Métricas de la semana (leads, conversiones, etc.)
- Actividades realizadas
- Problemas encontrados

### Output
- Reporte en `outputs/reports/weekly-[fecha].md`
- Resumen ejecutivo
- Métricas vs objetivos
- Acciones para próxima semana

### Tiempo Estimado
~15 minutos
