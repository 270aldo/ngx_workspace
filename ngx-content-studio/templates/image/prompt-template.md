## Tips de Optimización

### Por Herramienta

**SORA 2:**
- Excelente para realismo fotográfico
- Usar descripciones cinematográficas
- Especificar estilo de cámara

**Midjourney:**
- Añadir "--ar 16:9" para aspect ratio
- Usar "--v 6" para última versión
- "--style raw" para menos estilización

**DALL-E:**
- Ser más literal y descriptivo
- Evitar terminología técnica de fotografía
- Enfocarse en descripción de escena

**Stable Diffusion:**
- Usar pesos con paréntesis: (palabra:1.2)
- Negative prompts más detallados
- Especificar modelo/checkpoint usado

## Workflow de Generación

```
1. DEFINIR OBJETIVO
   └─ ¿Para qué plataforma?
   └─ ¿Qué mensaje/mood?
   └─ ¿Dimensiones necesarias?

2. SELECCIONAR TEMPLATE
   └─ Elegir categoría apropiada
   └─ Copiar template base
   └─ Adaptar a necesidad específica

3. CUSTOMIZAR PROMPT
   └─ Reemplazar [PLACEHOLDERS]
   └─ Añadir detalles específicos
   └─ Incluir elementos de marca NGX

4. GENERAR VARIACIONES
   └─ Crear 3-5 opciones
   └─ Comparar resultados
   └─ Iterar si necesario

5. REFINAR
   └─ Ajustar prompt si necesario
   └─ Regenerar mejores candidatos
   └─ Seleccionar final

6. POST-PROCESS
   └─ Ajustes menores en editor
   └─ Añadir texto/branding
   └─ Exportar en formato correcto
```
