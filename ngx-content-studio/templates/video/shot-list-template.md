## Referencia Visual

### Tipos de Shot

| Código | Nombre | Descripción |
|--------|--------|-------------|
| EWS | Extreme Wide Shot | Establece locación, sujeto pequeño |
| WS | Wide Shot | Sujeto completo en cuadro |
| MWS | Medium Wide Shot | Sujeto de rodillas para arriba |
| MS | Medium Shot | Sujeto de cintura para arriba |
| MCU | Medium Close-Up | Sujeto de pecho para arriba |
| CU | Close-Up | Rostro llena el cuadro |
| ECU | Extreme Close-Up | Detalle (ojos, manos, etc.) |
| OTS | Over the Shoulder | Desde atrás del hombro |
| POV | Point of View | Perspectiva del sujeto |
| INSERT | Insert | Detalle de objeto/acción |

### Movimientos de Cámara

| Código | Nombre | Descripción |
|--------|--------|-------------|
| STATIC | Estático | Sin movimiento |
| PAN | Pan | Rotación horizontal |
| TILT | Tilt | Rotación vertical |
| DOLLY | Dolly | Movimiento hacia/desde sujeto |
| TRUCK | Truck | Movimiento lateral |
| CRANE | Crane | Movimiento vertical |
| HANDHELD | Handheld | Movimiento orgánico |
| SLIDER | Slider | Movimiento corto horizontal |
| ORBIT | Orbit | Movimiento circular |
| PUSH | Push In | Zoom o dolly hacia sujeto |
| PULL | Pull Out | Zoom o dolly desde sujeto |

### Ángulos de Cámara

| Código | Nombre | Efecto |
|--------|--------|--------|
| EYE | Eye Level | Neutral, natural |
| HIGH | High Angle | Sujeto se ve pequeño/vulnerable |
| LOW | Low Angle | Sujeto se ve poderoso |
| DUTCH | Dutch Angle | Tensión, dinamismo |
| BIRD | Bird's Eye | Vista desde arriba |
| WORM | Worm's Eye | Vista desde abajo |
