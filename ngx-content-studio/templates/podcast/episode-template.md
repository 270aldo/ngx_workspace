## Script/Notas

### Pre-Roll (30 segundos)

```
[Sponsor message o disclaimer si aplica]

"Este episodio es presentado por [SPONSOR].
[Mensaje breve del sponsor - 2-3 oraciones]"
```

### Intro (1-2 minutos)

**Hook (15 segundos):**
```
[Frase o pregunta que capte atención inmediatamente]

Ejemplo: "¿Sabías que el 80% de las personas que empiezan
a entrenar abandonan en los primeros 3 meses? Hoy vamos
a hablar de por qué pasa esto y cómo evitarlo."
```

**Presentación (30-45 segundos):**
```
"Bienvenidos a [NOMBRE DEL PODCAST], el podcast donde
[propuesta de valor del show].

Soy [Tu nombre], [breve credencial], y hoy tenemos un
episodio [descripción del episodio].

[Si hay invitado:]
Y para hablar de esto, tengo el honor de tener a
[Nombre del invitado], [credencial del invitado].
[Nombre], bienvenido/a."
```

**Agenda (15-30 segundos):**
```
"En este episodio vamos a cubrir:
1. [Tema 1]
2. [Tema 2]
3. [Tema 3]

Y al final, [teaser del mejor contenido/takeaway]."
```
